## Overview

**Zenvora** is a modern e-commerce platform concept focused on the Direct-to-Consumer (D2C) business model and dropshipping.

The project aims to provide customers with an intuitive shopping experience while offering business owners tools to manage products, orders, customers, and store operations.

## Features & Project Roadmap

### Customer Storefront

- Modern and responsive homepage
- Product listings and product details
- Product search and category filtering
- Shopping cart and wishlist
- Secure customer authentication
- Checkout and order management
- Order tracking

### Admin Dashboard

- Dashboard overview and analytics
- Product and inventory management
- Order management
- Customer management
- Sales and revenue insights
- Store configuration

### Dropshipping Management

- Supplier and product management
- Inventory synchronization
- Order fulfillment workflow
- Shipment tracking
- Product pricing management

*Note: These are planned platform capabilities; implementation status depends on the current development stage.*

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/PALLAB2005/zenvora-ecommerce.git
```

### 2. Navigate to Project

```bash
cd zenvora-ecommerce
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

Open your browser and visit the local URL displayed in your terminal.

## Available Scripts
